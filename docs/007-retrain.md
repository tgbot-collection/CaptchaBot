# Story 007：手动导出 D1、重新训练和评估

## 依赖
Story 002、005–006。

## 开发任务
- CLI 从 D1 导出已审核 `spam` / `ham`，与 `spam.txt` 合并、去重并保留来源；绝不使用 pending 或仅凭昵称怀疑的账号。
- 不论 Ham 数量多少，都能用已确认 Spam 重新训练相似度索引。
- 当真实 Ham 足够时，**可选**训练字符 TF-IDF + Logistic Regression 二分类器。不得把任意样本量门槛当作质量保证；报告数量和类别不平衡风险。
- 避免相似模板/同一用户数据在训练集和测试集间泄漏；可按模板分组或按时间切分；有足够评估样本时报告 Precision、Recall、误报及混淆矩阵。
- 用固定回归样本集与旧模型对比；证据不足时要求人工批准，不宣称自动改进。
- 模型文件和 manifest 版本化，记录数据集 hash、样本数、参数、指标及 Schema 兼容性；只手动构建，不自动部署。
- 提供可复现 CLI 命令和回滚说明。

## 验收标准
- Ham 为零时仍可只用 `spam.txt` 训练。
- 已审核 Ham 只在真实存在时用于监督分类器。
- 重训不会原地覆盖已部署模型文件。
- 填写 `docs/notes/007-notes.md` 并更新进度。
