# Story 019：本地 D1 样本审核网页

通过单一 HTML 页面查看并人工审核 D1 的 `samples`。Cloudflare D1 API 拒绝本地文件的跨域预检，因此由现有 Python 环境提供本机网页服务和 D1 请求。macOS 支持通过启动文件双击打开。

## 验收条件

- 表格有 `id`、`message_json`、`text`、`status`、`action` 列，可悬停预览并一键复制 JSON，显示已审核标签。
- 显示全部样本总数和当前筛选的匹配条数，两项计数覆盖所有页。
- 支持状态筛选、分页、当前页多选与全选，支持单条和批量 `delete`、`spam`、`ham`。
- 标注复用人工运维语义，删除前确认并只删除 D1 样本。操作失败明确显示，D1 请求成功后再显示操作成功。
- 使用现有 D1 配置和 `SPAM_ADMIN_ID`，凭证保留在 Python 进程。服务仅绑定本机，显式启动，沿用参数化 REST API。使用模拟 D1 验证，无需操作真实样本。

## 范围

默认展示 pending。状态筛选也可直接查看 Spam 或 Ham，翻页与切换筛选时清空选择。人工标注沿用 Story 012，可纠正既有标签。删除通过单条 SQL 提交，重试时已不存在的样本视为已达到删除目标。网页只操作 D1，Telegram 审核通知和 Redis 聚合计数按现有生命周期处理。
