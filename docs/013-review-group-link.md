# Story 013：审核通知群组链接

## 目标

管理员收到 Spam 数据审核通知时，显示消息来源群组的名称，并将群名渲染为可点击链接，便于直接进入群组核对上下文。

## 范围

- 发送审核通知前，使用样本已有的 `message.chat_id` 查询当前群资料。
- 公开群使用 `https://t.me/<username>`；没有公开 username 的超级群使用 Telegram 官方私有消息链接 `https://t.me/c/<channel>/<message_id>`，点击后进入对应群。
- 群名和链接按 Telegram HTML 消息要求转义；继续关闭网页预览。
- 群资料查询或链接生成失败时，仍发送审核通知，并显示无链接的“未知群组”。
- 不修改统一样本 Schema、D1 Migration、callback 协议、标签语义、模型或任何管理动作。

## 不可破坏的边界

- 群资料查询只能发生在规则消息已删除、D1 pending 已成功写入之后，不能进入关键词删除关键路径。
- 查询失败不得丢失 pending、阻止通知或伪造保存成功。
- 日志只记录异常类型，不记录群 ID、群名、消息内容、Bio 或其他私密标识符。
- 现有 pending 记录必须无需回填即可在发送审核通知时获得群名链接。

## 验收条件

- 公开群审核通知包含已转义的可点击群名，链接为公开 username 地址。
- 私有超级群审核通知包含已转义的可点击群名，链接使用正确转换后的 `t.me/c` 地址和原消息 ID。
- 群资料读取失败时审核通知仍正常发送，按钮、D1 通知引用和审核流程保持原行为。
- 审核通知继续只包含 `✅ Spam` / `❌ Not Spam` 两个 callback 按钮，并关闭链接预览。
- 定向测试、完整测试、编译检查和 `git diff --check` 通过。
