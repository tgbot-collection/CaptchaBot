# Story 009：按群组选择普通消息采集与人工审核

## 目标
通过显式群组白名单收集普通聊天中的人工 Ham/Spam 标签。规则删除行为与模型建议权限不变。

## 范围与验收
- `SPAM_CAPTURE_GROUPS` 默认关闭；`all` 明确允许所有群；负数群 ID 逗号分隔时仅允许指定群。错误值启动失败。
- 只采集未命中现有规则、具有文本或 caption 的普通群消息。采集前同步快照，随后使用已有有界队列异步写 D1；不查询普通消息发送者的 Bio。
- 样本来源为 `group`、状态为 `pending`、标签为 NULL。普通消息不自动通知管理员；管理员私聊 `/review` 主动领取最早未领取记录，仍用既有两个按钮人工审核。
- 导出训练数据仍只接受人工 `reviewed` 样本。D1 Migration 保留原记录及审核引用，可重复执行；先迁移，再启用采集。
- 现有关键词命中仍立即删除，模型结果不会触发管理动作。

## 边界
全量允许群内的文本消息会持续增长，队列满时可丢样；不保证每条消息都被持久化。纯媒体无文本消息不参与当前文本模型训练，因此不采集。用户人工决定 D1 数据保留与删除。
