# Story 024：普通群消息采集排除列表

## 目标与范围

在开启全部群采集时排除不需要的群样本，复用既有群选择入口。不按语言检测，不清理历史数据。

## 验收条件

- 新增 `SPAM_CAPTURE_EXCLUDE_GROUPS`，默认空；接受逗号分隔的负数群 ID，允许周围空白并去重，非法格式在配置加载时拒绝。
- 排除优先于 `SPAM_CAPTURE_GROUPS=all` 和指定群列表；排除配置本身不启用普通采集，功能总开关继续有效。
- 排除群的普通消息不进入采集队列；其他允许群维持现有行为。
- 排除群命中既有关键词时仍立即删除，并保存 `rule/pending` 快照；删除前不新增网络请求。
- README 提供配置及重启说明，明确既有 D1 样本保持原状。
